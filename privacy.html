字幕转表格隐私政策

生效日期：2026年11月21日

“字幕转表格”是一款在 macOS 本地处理字幕文件并导出表格的工具。

简要说明：字幕内容和导出结果默认仅在你的 Mac 本地处理，不会自动上传到开发者服务器。

1. 数据处理

应用仅在你主动选择或拖入字幕文件时读取该文件，并仅在你主动导出时向你指定的位置写入文件。字幕解析、角色匹配、人工校对和表格生成均在设备本地完成。

2. 数据收集

应用不要求注册账号，不包含广告、跟踪或第三方分析 SDK，不向开发者服务器上传字幕内容、导出结果或使用数据。

3. 本地设置

应用使用 macOS 的 UserDefaults 在本机保存处理模式、角色人数、角色名称、编码、时间容差等偏好设置。这些设置仅供本应用自身读取，不用于跨应用或跨网站跟踪。

4. 系统权限

应用使用 macOS App Sandbox，仅访问你通过系统文件选择器明确选择的文件和保存位置。

5. 第三方服务

应用当前不集成需要上传字幕数据的第三方云服务。

6. 政策更新

如果未来版本的数据处理方式发生变化，本页面会更新相应说明和生效日期。

7. 联系与支持

如对本隐私政策或应用的数据处理有疑问，可通过 GitHub Issues 联系支持。
