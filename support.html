字幕转表格技术支持

适用于 macOS 版“字幕转表格”

字幕转表格支持 SRT 字幕的多轨整理、多角色识别、结果人工校对，以及 Excel、CSV 和表格复制。

遇到问题时

请尽量提供以下信息：

  • macOS 版本
  • 字幕转表格版本与 Build 号
  • 问题发生步骤
  • 问题截图或报错信息
  • 可复现问题的示例 SRT（仅在不涉及敏感内容时提供）

联系支持

请在 GitHub Issues 中提交问题。建议标题简要描述故障，并在正文中附上上述信息。

提交技术支持问题

隐私提示

字幕文件默认仅在设备本地处理，不会自动上传。提交 Issue 时，请不要上传包含客户隐私、商业秘密或其他敏感信息的真实字幕文件。
